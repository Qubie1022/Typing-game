# TypeQuest 冒險打字王

賽博龐克風格的英文打字練習網站。扮演抵禦病毒入侵的網路駭客，邊闖關邊練指法、背單字。純前端，不需要安裝套件或後端。

## 功能

- **分階段指法教學**：從基本鍵 ASDF JKL; 開始，虛擬雙手會依下一個要打的字母移動，並標示該用哪根手指。
- **單字融合**：關卡內容從指法練習字、國中小單字到職場單字，部分關卡附中文意思。
- **即時數據**：顯示 WPM、正確率與連擊數。
- **弱點分析**：記錄常按錯的鍵，自動產生「錯題特訓」關卡。
- **世界地圖**：新手村 → 上排山谷 → 下排礦坑 → 校園廣場 → 商務大樓 → 未來賽博都市（魔王戰），通關後解鎖下一關，戰鬥背景會隨進度慢慢轉換。
- **成就與解鎖**：11 個徽章與頭銜，以及隨等級解鎖的鍵盤音效、介面色彩、角色造型、動態背景。
- **每日任務**：完成可獲得雙倍經驗值。

## 使用方式

直接用瀏覽器開啟 `index.html` 即可。

### 部署到 GitHub Pages

1. 將此資料夾的檔案推上 GitHub 儲存庫。
2. 到儲存庫的 **Settings → Pages**。
3. Source 選擇 **Deploy from a branch**，Branch 選 `main`，資料夾選 `/ (root)`，儲存。
4. 稍待片刻即可在 `https://<你的帳號>.github.io/<儲存庫名稱>/` 開啟。

## 專案結構

```
index.html   頁面結構
style.css    樣式
script.js    遊戲邏輯、關卡資料、虛擬雙手動畫
```

## 自訂

- 新增單字或關卡：編輯 `script.js` 中的 `STAGES`（單字格式為 `英文:中文`，以逗號分隔）。
- 調整關卡背景色：編輯 `ZONES`。
- 徽章、造型、背景與解鎖等級：編輯 `BADGES`、`AVS`、`BGS`、`SOUNDS`、`THEMES`。

## 注意

- 進度（經驗值、星等、徽章、錯誤紀錄）儲存在瀏覽器的 localStorage，換裝置或清除瀏覽器資料會消失。
- 網頁字型使用 Google Fonts（Chakra Petch），離線時會自動使用系統字型。
- 音效使用瀏覽器內建的 Web Audio，需要在使用者按下鍵盤後才會發聲。

# TypeQuest 冒險打字王

一款在瀏覽器裡玩的英文打字闖關遊戲。單字會從上方掉落，在碰到底部之前把它們打出來，邊玩邊練習指法與英文單字。整個遊戲只有一個 `index.html`，不需要安裝任何東西，也不需要後端。

## 功能

- **六個關卡**：新手村 → 上排山谷 → 下排礦坑 → 校園廣場 → 商務大樓 → 最終魔王（長句輸入）。
- **中文提示**：每個掉落的單字下方都會顯示中文意思。
- **虛擬鍵盤與手指動畫**：依手指分色，提示下一個要按的鍵與該用哪根手指。校園廣場與商務大樓可自由開啟或關閉。
- **單字速度拖曳桿**：每個會掉單字的關卡都可以依自己的程度調整速度。
- **錯題特訓**：自動收集打錯的單字，集中練習。
- **每日任務**：完成可獲得雙倍經驗值，並記錄連續登入天數。
- **經驗值與等級**：每升一級經驗值重新計算。升級可解鎖音效、介面色彩、角色造型與動態背景。
- **成就徽章**：未達成的徽章只顯示達成條件，達成後才顯示名稱，並自動排到清單上方。
- **羊皮紙藏寶圖風格**：主畫面與各關卡採用統一的視覺設計。

## 如何使用

### 直接開啟
下載專案後，用瀏覽器開啟 `index.html` 即可。

### 部署到 GitHub Pages
1. 把這個資料夾推到你的 GitHub 儲存庫（`index.html` 放在根目錄）。
2. 到儲存庫的 **Settings → Pages**。
3. **Source** 選 *Deploy from a branch*，Branch 選 `main`，資料夾選 `/ (root)`，按 **Save**。
4. 等待一兩分鐘，網址會是 `https://<你的帳號>.github.io/<儲存庫名稱>/`。

## 資料儲存

進度（等級、徽章、錯題、設定等）只存在使用者自己瀏覽器的 `localStorage`，鍵名為 `tq`，不會上傳到任何伺服器。換瀏覽器或清除網站資料，進度就會消失。想重置進度，可以在瀏覽器開發者工具的 Console 輸入：

```js
localStorage.removeItem("tq"); location.reload();
```

## 外部資源

頁面會從 Google Fonts 載入 Chakra Petch 字體；沒有網路時會自動使用系統字體，遊戲仍可正常運作。
